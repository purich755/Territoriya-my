# «Территория МЫ» — демо главной страницы

Демо для холодной продажи: одна страница, концепция «Территория — это не место. Это мы».
Сайт — карта территории, которой нет на картах: горизонтали, координаты, легенда, маршруты.
В `<head>` стоит `noindex, nofollow` (на сайте фото детей).

## Как запустить

```bash
node tools/serve.mjs 8390
```

Открыть http://localhost:8390/. Сборки нет: HTML + CSS + vanilla JS, библиотеки с jsDelivr
(GSAP 3.13 + ScrollTrigger/Draggable/InertiaPlugin/Flip, Lenis 1.3.11, SplitType 0.3.4, simplex-noise 4.0.3).
Прелоадер показывается один раз за сессию; чтобы увидеть снова — новая вкладка или `sessionStorage.clear()`.

Инструменты самопроверки (нужен Chrome): `tools/shots.mjs` (сплошной проход скриншотами),
`tools/interact.mjs` (16 проверок интерактива), `tools/overflow.mjs` (горизонтальный скролл на 360–1920),
`tools/spot.mjs` (скриншот одной секции).

## Что проверено

- Lighthouse, десктоп: Performance 92, Accessibility 100, Best Practices 100.
  SEO 63 — только из-за `noindex`, так задумано.
- Горизонтального скролла нет на 360 / 375 / 768 / 1024 / 1440 / 1920.
- Интерактив (десктоп и 390 px): прелоадер, тумблер аудитории, компас и якоря, аккордеон с клавиатуры,
  отзывы, перетаскивание фото, лайтбокс (клик, стрелки, Esc), «Разложить по порядку»; на телефоне — свайп стопки и тап.
- `prefers-reduced-motion`: без прелоадера, частиц и пинов, всё видно сразу.

## Что уточнить у клиента

1. **Текущая база.** ГК «Регина» (Мамадыш) — по постам канала за 2025–2026. Подтвердить; места ДОЛ «Чайка»
   и ДОЛ «Родничок» на схеме не отмечены, т.к. их расположение не удалось проверить.
2. **Рейтинг.** «1-е место в рейтинге лагерей РТ» — чей рейтинг и какого года. На сайте помечено «по данным лагеря».
3. **Возраст лагеря.** По брифу на сайте «25+ лет». В канале (пост от 29.09.2026) лагерю «стукнуло 27 лет» —
   можно писать точную цифру, если клиент подтвердит год основания.
4. **Телефон.** На Яндекс.Картах и в канале — +7 (927) 039-42-22, в черновике сайта встречался 038-42-22. На сайте стоит 039.
5. **Свечка.** В постах лета 2026 есть «отрядные свечки» — проверить, что описание («тихий вечерний разговор
   отрядом при свече») совпадает с тем, как это устроено.
6. **Согласия на фото детей** для публичного сайта. Пока демо закрыто от поиска.
7. **Слоган** «Лагерь, где становятся личностью» — официальный ли.
8. **Школа вожатых.** В канале есть набор «кандидатов в советники» на весенней смене — можно рассказать подробнее
   в блоке «Путь».
9. Описание «Паутинки» и переписка «Мам, я побежал» написаны по мотивам постов и отзывов — дать на вычитку.
10. Цитаты отзывов сокращены; имена даны как на Яндекс.Картах (имя + инициал). Согласовать публикацию.
